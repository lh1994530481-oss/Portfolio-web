检查连接状态并导入当前网站内容。

正式启用步骤

  1. 在 Supabase SQL Editor 执行 admin/supabase-schema.sql。
  2. 在 Authentication 创建管理员账号，并将 User UID 写入 portfolio_admins。
  3. 在 admin/config.js 填入 Project URL、Publishable Key 和管理员邮箱。
  4. 登录本后台，点击“导入现有网站内容”。
