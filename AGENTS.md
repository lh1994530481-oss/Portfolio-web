# Deployment workflow

- The production branch is `main`.
- Keep the external URLs listed in `README.md` unchanged unless the repository or GitHub Pages configuration changes.
- After code or content changes, commit and push the affected repository, then verify the corresponding GitHub Pages URL.
- Changes to the embedded admin or shared content API must also be mirrored to `D:\codex\Personal-backend` and pushed to `Personal-backend` in the same delivery.
- Keep local audit artifacts out of commits unless the user explicitly asks to publish them.
